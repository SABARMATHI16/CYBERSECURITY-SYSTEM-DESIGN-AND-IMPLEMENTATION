**Project 1 – Cloud-Based Adaptive Hybrid Intrusion Detection System**



**Justification for Selection**



**1.Increasing Network Attacks: Modern organizations face continuous network-based attacks, making effective network monitoring an important cybersecurity requirement.**

**2.Limitations of Traditional IDS: Conventional IDS solutions that depend mainly on predefined signatures may have difficulty identifying new or previously unseen attack patterns.**

**3.Detection of Known and Unknown Attacks: The proposed system combines signature-based detection with anomaly detection to address both known and abnormal network activities.**

**4.Machine Learning Integration: Machine learning provides an opportunity to identify attack patterns from network-traffic features and improve intelligent threat detection.**

**5.Multiple Detection Layers: Combining signature detection, ML-based detection and anomaly detection provides multiple sources of evidence instead of relying on a single detection method.**

**6.Threat Intelligence Enrichment: Threat-intelligence information can provide additional context about suspicious sources and help improve the assessment of detected events.**

**7.Risk-Based Decision Making: A unified risk score can help determine the severity of detected network activity and prioritize security events.**

**8.Automated Response: The system can move beyond detection by supporting appropriate actions such as monitoring, alerting or blocking based on the calculated risk.**

**9.Cloud Deployment Potential: A cloud-based architecture provides scope for centralized traffic analysis, security-event logging, monitoring and scalable processing.**

**10.Strong Development Scope: The project provides practical scope for implementing and evaluating network security, machine learning, anomaly detection, threat intelligence and automated response within one integrated system.**
