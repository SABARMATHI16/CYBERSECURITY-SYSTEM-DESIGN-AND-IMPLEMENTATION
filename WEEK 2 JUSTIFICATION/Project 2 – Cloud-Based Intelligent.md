**Project 2 – Cloud-Based Intelligent User Behavior Risk Analysis \& Adaptive Authentication System**



**Justification for Selection**



**1.Risk of Credential Compromise: Stolen or compromised credentials can allow attackers to access systems while appearing to be legitimate users.**

**2.Limitations of Credential-Based Authentication: Checking only the username and password does not provide sufficient information about whether the current login behavior is trustworthy.**

**3.Behavior-Based Security: The project introduces user behavior analysis as an additional security layer to conventional authentication.**

**4.Context-Aware Analysis: Login context such as device, IP address, location, time and browser can provide useful information for evaluating the legitimacy of an access attempt.**

**5.Machine Learning Application: Machine learning can be used to identify deviations from a user's normal behavioral patterns.**

**6.Individual User Profiles: The system can establish behavioral patterns for individual users and compare new login activity against those expected patterns.**

**7.Risk-Based Authentication: Instead of applying the same authentication requirement to every login, the system can generate a risk score based on the observed security context.**

**8.Adaptive Security Response: Different risk levels can trigger different actions, such as allowing normal access, requesting MFA for suspicious activity or blocking high-risk attempts.**

**9.Cloud Deployment Potential: A cloud-based architecture can support centralized authentication monitoring, behavioral-data processing, event logging and security dashboards.**

**10.Strong Identity-Security Scope: The project provides practical scope for combining authentication, behavioral analysis, machine learning, risk assessment and adaptive verification into an integrated identity-security solution.**
