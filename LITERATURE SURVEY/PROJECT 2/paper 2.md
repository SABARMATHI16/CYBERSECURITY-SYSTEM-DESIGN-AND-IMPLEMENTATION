Paper 02
Title

Novel and Efficient Privacy-Preserving Continuous Authentication

Authors

Ahmed Fraz Baig, Sigurd Eskeland, Bian Yang

Year

2024

Publication

Cryptography – MDPI

1. Problem Addressed

Continuous authentication requires continuous processing of behavioral and contextual information, which can create privacy concerns because these data may contain sensitive user information.

2. Proposed Approach

The paper proposes privacy-preserving protocols for continuous authentication that protect sensitive user attributes while still enabling authentication decisions.

3. Technologies / Methods Used
Continuous Authentication
Behavioral Data
Contextual Data
Biometrics
Partial Homomorphic Encryption
Privacy-Preserving Protocols
4. Relevance to Our Project

The paper is relevant because our cloud-based authentication system will process behavioral and contextual information.

5. Limitation

The paper focuses strongly on privacy-preserving continuous-authentication protocols rather than a complete adaptive authentication system with risk-based MFA and blocking.

6. Research Gap

There is scope for combining privacy-aware behavioral analysis with a practical risk-based adaptive authentication mechanism.

7. Proposed Contribution in Our Project

Our system will investigate behavioral and contextual risk analysis and use the resulting risk level to dynamically select the required authentication response.
