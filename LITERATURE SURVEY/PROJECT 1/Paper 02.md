Paper 02
Title

Improved Intrusion Detection Based on Hybrid Deep Learning Models and Federated Learning

Year

2024

Publication

Sensors – MDPI

1. Problem Addressed

The paper investigates improving intrusion detection using hybrid deep-learning models while supporting distributed learning through federated learning.

2. Proposed Approach

A hybrid deep-learning approach is used to improve network intrusion detection while federated learning is considered for distributed security-data processing.

3. Technologies / Methods Used
Deep Learning
Hybrid Models
Federated Learning
Network Intrusion Detection
Distributed Learning
4. Relevance to Our Project

The paper supports the use of multiple learning techniques for intelligent intrusion detection and provides useful direction for scalable security analysis.

5. Limitation

The work focuses primarily on hybrid deep-learning and federated-learning-based detection rather than integrating threat intelligence and automated incident response.

6. Research Gap

An integrated IDS can combine intelligent detection with risk scoring, external threat intelligence and automated response.

7. Proposed Contribution in Our Project

Our project will investigate a cloud-based hybrid architecture where multiple detection results are combined before making a risk-based security decision.
