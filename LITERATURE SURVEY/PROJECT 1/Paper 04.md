Title

Design and Analysis of an Effective Architecture for Machine Learning Based Intrusion Detection Systems

Year

2025

Publication

MDPI – Network

1. Problem Addressed

The paper investigates the design of effective machine-learning-based intrusion detection architectures capable of identifying malicious network activity.

2. Proposed Approach

The study develops and evaluates an ML-based IDS architecture for detecting malicious network traffic.

3. Technologies / Methods Used
Machine Learning
Network Traffic Analysis
Intrusion Detection
Classification
IDS Architecture
4. Relevance to Our Project

This paper is useful for designing the detection architecture of our proposed cloud-based IDS.

5. Limitation

The architecture focuses on intrusion detection rather than providing a complete adaptive security platform with threat intelligence, risk scoring and automated response.

6. Research Gap

The detection architecture can be extended by adding contextual security information and automated decision-making.

7. Proposed Contribution in Our Project

Our proposed system will extend the IDS architecture with anomaly detection, threat intelligence, risk scoring, automated response and cloud monitoring.
