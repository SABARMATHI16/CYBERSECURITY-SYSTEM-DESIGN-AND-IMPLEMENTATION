Paper 05
Title

Smart Framework for Industrial IoT and Cloud Computing Network Intrusion Detection Using a ConvLSTM-Based Deep Learning Model

Authors

Ala’ Abdulmajid Eshmawi, Asma Aldrees, Raed Alharthi

Year

2025

Publication

Frontiers in Computer Science

1. Problem Addressed

The paper addresses network-security challenges in environments involving Industrial IoT and cloud computing, where large volumes of network traffic need to be monitored for malicious activity.

2. Proposed Approach

The study proposes a deep-learning-based intrusion detection framework using ConvLSTM for network attack detection.

3. Technologies / Methods Used
Deep Learning
ConvLSTM
Network Intrusion Detection
Industrial IoT
Cloud Computing
4. Relevance to Our Project

This paper is particularly relevant because our proposed project also targets a cloud-based intrusion detection environment.

5. Limitation

The proposed approach focuses mainly on deep-learning-based detection and does not cover the complete combination of threat intelligence, risk scoring and automated response in our proposed architecture.

6. Research Gap

There is scope for developing a cloud-based IDS that combines intelligent detection with threat context and automated security decisions.

7. Proposed Contribution in Our Project

Our project will extend intelligent detection into a complete cloud security workflow involving detection → threat enrichment → risk scoring → response → monitoring.
